# Sistema-de-Caixa_Rumspringa-Conveniencia-v.7.0
Um sistema completo de controle de caixa, vendas e retiradas, totalmente local (sem nuvem), ideal para pequenos comércios, tabacarias, bares e conveniências. Desenvolvido para ser leve, rápido, seguro e funcional diretamente no navegador, com armazenamento automático via localStorage. Por Mr. Canatto. (v7.0 BETA_LEITOR_CODIGO)
