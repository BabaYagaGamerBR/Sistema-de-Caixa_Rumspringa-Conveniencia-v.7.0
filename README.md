# Sistema de Caixa – Rumspringa Conveniência e Tabacaria (v7.0)

Sistema de Caixa desenvolvido para gerenciamento completo de operações de conveniência e tabacaria, focado em uso real de PDV (Ponto de Venda), controle financeiro diário e organização operacional.

O projeto foi criado com foco em:

* simplicidade;
* velocidade operacional;
* funcionamento local sem necessidade de servidor;
* estabilidade para uso diário;
* interface moderna e responsiva.

## Principais Funcionalidades

### 📊 Dashboard

* Resumo financeiro diário;
* Controle de vendas do dia;
* Controle de fiado;
* Dinheiro em gaveta;
* Últimas transações em tempo real;
* Edição rápida de transações.

### 🛒 Venda / PDV

* Sistema completo de carrinho;
* Busca rápida de produtos;
* Suporte a leitor de código de barras USB;
* Modo rápido e modo quantidade manual;
* Itens avulsos;
* Controle de desconto;
* Controle de troco;
* Venda em dinheiro, pix, débito, crédito e fiado;
* Impressão de cupom.

### 👥 Clientes / Fiado

* Cadastro de clientes;
* Controle de dívida;
* Registro de pagamentos;
* Fechamento de conta individual;
* Histórico de compras;
* Impressão de relatório do cliente.

### 📦 Estoque

* Cadastro e edição de produtos;
* Controle de quantidade;
* Controle por código;
* Integração com leitor de código de barras.

### 💸 Retiradas

* Registro de retiradas físicas e digitais;
* Controle separado por origem;
* Integração com relatórios e fechamento.

### 📄 Relatórios

* Relatórios financeiros completos;
* Impressão A4;
* Controle por período;
* Totais por forma de pagamento;
* Controle de retiradas;
* Controle correto de fiado;
* Somativa digital;
* Exportação CSV e Excel.

### 🔒 Fechamento Diário

* Fechamento completo do caixa;
* Controle de troco inicial;
* Saldo digital inicial/final;
* Controle de retiradas;
* Impressão profissional A4;
* Histórico de fechamentos.

### 📜 Auditoria

* Registro detalhado de operações;
* Histórico de vendas;
* Alterações;
* Exclusões;
* Pagamentos de fiado;
* Controle administrativo.

### ⚙️ Backup e Configurações

* Backup completo em JSON;
* Restauração de dados;
* Controle de taxas;
* Configurações persistentes.

## Objetivo do Projeto

O objetivo do Sistema de Caixa Rumspringa é oferecer uma solução prática, rápida e funcional para pequenos comércios, conveniências e tabacarias, sem depender de mensalidades, servidores externos ou sistemas complexos.
